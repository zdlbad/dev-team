# 概念页小样（2026-10-29，等人定）

项目所有者 10-29 提的三件事，加上两句补充：

1. **一次认知消化量**：人一次能装进脑子的量。字太多、信息太密，人一次装不下、失焦；太少又没东西学。**这是一个指导，不是规则，没有硬性标准**（10-31 他定的：不要「七样上下、过九标红」这种计数，也不要把它写成规矩）；写给人看的东西时心里掂一掂，像这一页现在的样子——一张图加一段简短的文字解释——就差不多。
2. **以领域事件为焦点，用图解释，文字只当补充**。
3. **本质、类比、例子那一套不要了**。
4. 业务页上**按主题看三层**那一页不要了（语句文件照旧留着，模型的 traces、校验还挂着它们，只是不再给人看那张表）。
5. **故事讲领域事件**（发生的过程，动态的）；**概念讲一样东西**（它是什么、前因后果、跟别的东西的关系，静态的）；**原来的「关系」页并进概念**，仍是图加文字补充。写成 JSON、页面画（他选的）。

小样：`小样.html`，拿参与者当例子，浏览器直接打开。

## 小样上有什么

- 左栏概念清单（照框架概念图出场先后编号）、每张的「未定 / 已定 / 改过」。
- **这一页的作用是说明业务概念**（10-31 他定的）：**定义**（照手册、法规的说法，带出处；别的文件上叫什么也跟在这儿）+ **通俗易懂的解释**（紧跟在定义底下一段，不带标签，用大白话把定义讲明白，两三句）+ 图（它跟别的东西什么关系）。「定下」钮和「未定 / 已定 / 改过」的标记都在标题那一行。
- **图**：三列，不标列名。左边是跟它有关系的纸和各方，中间它本身（标题加四五条要紧的事实名，指着看解释），右边是它牵出的东西。**不讲前因后果、不画事件**（10-29 他定的：概念说关系，发生的过程归故事）。
- **框的形状和颜色**（10-31 他定的）：圆角是角色、偏直角是数据；角色淡蓝、数据淡绿，就这两种。这次解释的概念也照它自己是角色还是数据上色（参与者圆角淡蓝、服务偏直角淡绿），不另给颜色，靠摆在中间、边框粗一点认出来。原料里的纸、推出来的、政府定死的清单这些细分不再用颜色区分，只在指着时的解释里说。
- **线只有一种，线上写的就是关系**（「批了她能用的服务类型」「跟她签协议、报入场、派照护伙伴」「名下有几笔，通知书定的」）。原来关系页的推出、也能、再缩小三种画法不要了（10-31 他定的），要说是哪种关系，写在线上的字里。
- **图例只两项**：角色（圆角）、数据（偏直角）。「指着看补充、点一下钉住」这类说明不写在页面上。
- **图下面什么都没有**（10-31 他定的：一线一行的表、「纸上的栏」「模型师的细节」两个折叠块、拿例子看，都不要）。文字补充只在指着线或框时浮出来：说的是、故事哪一步、出处、语句编号；点一下钉住。
- **「样子」表（纸上的栏）和模型师写的「细节」从此不写了**（10-31 他定的）：聚合设计的「属性」页本来就列每个事实装在哪、从哪来，模型师整理时直接读原料。`business/概念/*.md` 里的样子表、`model/概念/*.md` 整个目录，改完就删。

## 数据形状（真做时 `business/概念/<nn>-<概念>.json`，业务分析写）

```jsonc
{ "title": "参与者",
  "definition": "照手册、法规的说法，一句",
  "definitionSource?": "§ 与行号；别的文件上叫什么也写这儿",
  "explain": "大白话讲明白定义，两三句",
  "nodes": [ { "id": "notice", "title": "决定通知书", "sub?": "评估代表寄来", "kind": "paper|party|self|derived|fixed", "side": "left|right",
               "facts?": [ { "name": "分级与路径", "text": "定她有哪几种基金" } ], "source?": "§6.6" } ],
  "edges": [ { "id": "1", "from": "notice", "to": "pt", "label": "写着她批了哪一级、哪条路径",
               "text": "一两句补充", "story?": "<故事名> #<步骤>", "source?": "", "traces?": ["R-522"] } ],
  "questions": [],
  "confirmed?": { "at": "", "stamp": "" } }
```

`kind: self` 的节点只有一个，就是这张卡讲的东西。聚合设计的 `refs` 写「<概念名> #<线>」，跟原来指关系的线一样。
