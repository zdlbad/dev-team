|---|---|
| [00-principles.md](00-principles.md) | 骨架：一个源头、两份真相、一把尺子；底层三元素；可编码 / 可解码；两层模型；放置规则；两速决策；每个工件只有一个写入角色 |
| [01-phases-and-slices.md](01-phases-and-slices.md) | 三阶段；阶段一：粗读 → 战略一次 → 按段落点亮；**开发范围怎么切**（故事线 → 段落 = 切片 → 模块职责 = PR → 聚合改动 = commit；判据；分支按轮次；改说法切片的门禁）；**段落切片的周期**与**实现切片**；差异回流；十个角色与写入权；还没落进工具的 |

| [03-coding-standard.md](03-coding-standard.md) | 基础构建块、领域层、应用层、端口与适配器、结构化注释、解码规则汇总、禁止项、**测试的位置、命名与粒度** |
| [04-validation.md](04-validation.md) | 两个方向的检查项（机械 / 判断 / 人确认）、判断的可审计性、报告格式、**代码审查的七个角度（A–F + S）与两阶段** |
| [05-roles.md](05-roles.md) | 十个角色的读 / 写 / 方法 / 问人 / 不做；**开发指挥**（主持角色：调度、节奏、裁定分流、现场、写回）与状态看板 |
| [06-style.md](06-style.md) | 项目所有者的写法 S1–S8；与 03 的关系（冲突时 03 为准） |
| [07-business-layers.md](07-business-layers.md) | **业务分三层**（业务抽象 / 业务落地 / 应用行为）与五问判据；语句怎么写（正向陈述、一句一动作、标出处、`(层-种类)` 标签；能力 / 事实 / 约束 / 公式 / 触发 / 流程 / 情形七种）；五问取代使用语句；**点亮**（raw 是暗的，沿故事线 → 段落 → 模块 → 聚合 → 行为逐级点亮）；裁定分流；已有项目怎么过渡 |
