# 业务描述

每个主题一个 `.md`。陈述性语句，不写故事、步骤、角色矩阵。编号一经分配永不复用。

```markdown
## 目标
- [G-001] 协调员能为参与者制定预算

## 规则
- [R-001] (不变量) 预算总额不得超过参与者的核定额度
- [R-002] (反应)   预算被批准后，通知服务提供方
- [R-003] (推导)   剩余额度 = 核定额度 − 已分配

## 使用
- [U-001] (使用) 同一份预算可能被两个协调员同时打开修改
- [U-002] (使用) 协调员提交预算时可能连点两次
```

目标与规则说一次操作对不对；**使用**说这个系统会被怎么用（同时、重复、一次几条、失败处置、谁能看见）。使用语句原料里通常没有，由业务分析按五问主动问出来，模型必须回应每一条。
